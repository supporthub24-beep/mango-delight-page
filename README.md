# Mango Delight Page

আপনি চান আম বিক্রির জন্য একটা নতুন ল্যান্ডিং পেজ বানানো হোক।



আমি যা করব:

১. এখন সাইটে রাউটিং আর পেজগুলো কীভাবে সাজানো আছে সেটা দেখে নেব, যাতে নতুন পেজটা একই প্যাটার্নে বসে।

২. হোমপেজে যে ডিজাইন টোকেন, রঙ, ফন্ট আর কম্পোনেন্ট (হিরো, প্রোডাক্ট কার্ড, add to cart) ব্যবহার হচ্ছে সেগুলোই নতুন পেজে রিইউজ করব।

৩. ল্যান্ডিং পেজে থাকবে — একটা হিরো সেকশন, আমের ভ্যারাইটি সেকশন দাম ও add to cart বাটনসহ, কেন আমাদের কাছ থেকে কিনবেন সেকশন, আর একটা কল-টু-অ্যাকশন।

৪. মোবাইল রেসপন্সিভ, alt টেক্সট, লোডিং/এম্পটি স্টেট আর পেজ টাইটেল-মেটাডেটা ঠিক রাখব।

৫. শেষে বিল্ড/টাইপচেক চালিয়ে নিশ্চিত করব যেন কিছু ভাঙে না।



যা বাদ দিচ্ছি: পুরো সাইটের ডিজাইন বা রঙ বদলাব না, আর নতুন কোনো লাইব্রেরি যোগ করব না।
